# Ticket 01 — Homepage dorm discovery

## Goal

Build the landing page for RentaDorm Iloilo with a polished dorm listing layout, photo cards, and a location map.

## Tasks

- Replace the starter homepage with the RentaDorm Iloilo brand
- Add featured dorm cards with Iloilo-focused locations and pricing
- Add area filter buttons to browse by district
- Show selected dorm details and photo gallery
- Add an embedded map that updates for the selected dorm
- Ensure the page is responsive on mobile and desktop

## Definition of done

- The homepage loads without errors
- At least five dorm listings appear
- Selecting a dorm updates the detail view and map
- The design is neat and user-friendly for rental discovery
